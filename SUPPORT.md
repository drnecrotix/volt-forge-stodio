# Support

Thanks for using or following VoltForge Studio.

## Questions and Usage Help

VoltForge Studio is currently in early development and the public repository does not yet contain the application source code. For questions about the current project direction, documentation, or planned workflows, open a GitHub Discussion when discussions are available or use an Issue when the question relates to a concrete documentation or project problem.

## Bug Reports

Use the bug report template for reproducible problems. Include:

- what you expected to happen
- what actually happened
- steps to reproduce the problem
- operating system and relevant software versions
- screenshots or logs when they help explain the issue

Please avoid including secrets, API keys, tokens, passwords, or other private information.

## Feature Requests

Use the feature request template for new ideas. Describe the problem first, then the proposed behavior. Focused requests are easier to discuss and plan than large bundles of unrelated features.

## Security Issues

Do **not** report security vulnerabilities in public Issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Development Status

The project roadmap is documented in [ROADMAP.md](ROADMAP.md). The roadmap may change as source releases begin and technical constraints become clearer.
