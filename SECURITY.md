# Security Policy

## Supported Versions

Volt Forge Studio is currently in its initial development phase. Security updates will target the latest release on the default branch. A version support table will be added when stable releases are available.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Report security concerns privately by emailing `<security@example.com>`. Replace this placeholder with a monitored security address before publishing.

Include, when possible:

- A description of the vulnerability and its potential impact
- The affected component, version, or commit
- Reproduction steps or a minimal proof of concept
- Any known mitigations or workarounds
- A safe way to contact you for follow-up

We aim to acknowledge reports within five business days, assess their severity, and provide progress updates while remediation is underway. Please allow a reasonable period for a fix before public disclosure.

## Safe Harbor

Good-faith security research that avoids privacy violations, data destruction, service disruption, and unnecessary access will be treated as authorized within the scope of this policy. Comply with applicable law and stop testing if you encounter sensitive data.
